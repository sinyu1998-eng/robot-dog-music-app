🐕 机器狗蓝牙协议探测台

用途：把 XHY-RC 这类"没有 SDK 的玩具狗"变成可编程设备。
用法：连接 → 看服务/特征列表 → 手动发十六进制指令试探 → 找到每个动作对应的字节 → 填进底部指令表保存 → 主应用（index.html）即可驱动真狗。
⚠️ 必须用 http://localhost 打开，Chrome 的 Web Bluetooth 在 file:// 下会被禁用。
在本文件夹执行 python3 -m http.server 8000，然后浏览器访问 http://localhost:8000/ble-probe.html。
手机也能用：Chrome for Android 支持 Web Bluetooth；iOS Safari 不支持，iOS 请改用「抓包法」（见页面底部）。

⑥ 抓包法（iOS/安卓通用，最可靠）

安卓：设置 → 开发者选项 → 开启「启用蓝牙 HCI 嗅探日志」→ 用 XHY-RC 连接狗，每个动作停 2 秒依次按一遍 → 停止 → 取出 /data/misc/bluetooth/logs/btsnoop_hci.log（或 adb bugreport）→ 用 Wireshark 打开，过滤 btatt.opcode == 0x52（Write Command）和 0x12（Write Request）→ 每条动作对应的字节就出来了。
iOS：Mac 装 Xcode → Additional Tools → PacketLogger，用 iPhone 连狗操作，抓 ATT 写入包。
捷径（不用抓包）：用 nRF Connect 连上狗，逐个特征点写入试；或直接用本页 ③ 试探常见帧。
抓到后把"字节 → 动作"的对应关系填进 ⑤，主应用就能按音乐节拍发指令了。
