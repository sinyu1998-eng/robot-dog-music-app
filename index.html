你好！我是机器狗的音乐大脑 🧠。你可以：
① 点歌表演：「跳一首晴天」「表演一首悲伤的歌」
② 音乐问答：「周杰伦是什么风格」「这首歌 BPM 多少」
③ 求推荐：「推荐几首类似青花瓷的歌」
也可以点左边上传你自己的音乐，我会分析节奏和情绪后编舞。
RAG 检索库目前内置 24 首示例歌曲（见架构页）。语音输入需浏览器授权麦克风（Chromium 内核支持中文识别）。
数据流水线
上传音乐 → Web Audio 解码 → 能量包络 + 过零率 → BPM / 能量 / 明亮度
→ 情绪分类（兴奋/欢快/平静/低沉）→ 动作编排引擎（按节拍调度动作池）
→ RobotDogAdapter 适配层 → 当前：模拟狗 ｜ 未来：你的玩具狗协议
RAG 问答流水线
语音/文本 → 意图识别（点歌/问答/推荐）→ 检索（标题/艺人/曲风/情绪/标签 打分）
→ Top-K 结果 → 模板生成答案 + 相似推荐
生产版：检索换成向量 Embedding，生成换成 LLM API（接口已预留 askLLM()）
接真狗怎么做
代码底部有 class ToyDogAdapter 骨架：把 jump/spin/wag/bob... 映射成你玩具狗的蓝牙/串口指令（如 0x01 jump），
通过 Web Bluetooth 或树莓派中转发送即可。把你玩具狗的型号/协议文档发我，我帮你补全这一层。
